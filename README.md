## Installation Guide

**Prerequisites for your system**
- Install [node js](https://nodejs.org/en) and [git](https://git-scm.com/) in your system

**Now follow these commands**

- Download or clone the project
```bash
  git clone https://github.com/useridanurag/currency-converter.git
```

- Locate project directory
```bash
  cd currency-converter
```

- Install node modules
```bash
  npm install
```

- Run this project 
```bash
  npm run dev
```

**Project based learning**
- Developed a currency converter application that fetches real-time exchange rates via an API to
dynamically convert between different currencies. Users can select the source and target
currencies and input the amount to get an instant conversion. The app handles API data efficiently,
providing up-to-date rates for accurate conversions, and features an intuitive interface for easy use.
